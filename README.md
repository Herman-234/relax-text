A short text written to settle a reader — quiet evening imagery, slow pace,
no instructions, no sales talk. `main.py` (Python 3.13, standard library
only) writes it deterministically to `/output/entry.txt`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
